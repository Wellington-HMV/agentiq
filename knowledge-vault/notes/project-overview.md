# well-corp-sw

Personal CLI/TUI tool for a solo developer to orchestrate Claude multi-agent work
on their own projects. Hand off a goal; a parent agent (Claude Agent SDK) self-
organizes parent -> teams -> subagents, consults harness-standard knowledge vaults,
decides autonomously, and runs headless.

**GOAL:** reliable autonomy + a *legible replay* rendered as a living spatial scene
(library = vault, desk = thinking, path = delegation). The animated scene is opt-in
observability; legible replay is the product, not the spectacle.

Primary user: the solo dev (the author). Killer moment: open a finished run and
understand everything in under ~2 minutes from the scene alone — no raw logs.
